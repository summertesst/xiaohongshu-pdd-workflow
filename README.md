# 小红书 × 拼多多服饰商单工作流

把一次穿搭商单整理为可复用的流程：从已拍好的穿搭图出发，选出符合任务要求且可以绑定推广的商品，生成图片短语、小红书文案和待审核成品。

## 核心调整：先确认能推广，再做成品

原商品链接不等于可用的推广店铺词，也不等于推广商品词。先建立对应关系并确认可用，再锁定商品、写最终文案和合图，避免成品完成后重新选品。

“已锁定”的含义：商品匹配关系已经核对，本单要求的推广项已在对应任务中确认可用，且不属于禁投品；只有链接、搜索结果或提报记录，不算锁定。

## 教程中提取的规则

以下来自用户提供的教程，尚未在当前任务页面验证。若教程与实际任务或最新页面不一致，以实际任务要求为准。

| 项目 | 教程说明 | 工作流中的处理 |
|---|---|---|
| 推广店铺词 | 在对应任务的推广店铺／商品词入口，选择渠道后搜索；优先复制商品长标题，搜不到时精简为关键词 | 保存实际可选的店铺词，不只保存原商品链接 |
| 同款商品 | 教程允许选择展示同款商品的店铺 | 必须人工核对同款；不能把相似款自动标成同款 |
| 店铺词搜不到 | 可进入个人中心的提报商品入口，按页面流程提报店铺链接 | 记录提报状态，待审核并重新确认可用后再锁定 |
| 店铺提报状态 | 教程区分可提报、已入库、不达标／被占用等状态 | 不达标／被占用不能按已通过处理，必要时更换候选 |
| 提报等待 | 教程提到店铺提报后约 5 小时可能可搜到 | 只是教程参考时间，不承诺审核时效 |
| 推广商品词 | 可以搜索符合商品描述的词，不要求与店铺词一一对应 | 分开记录商品词与店铺词，不能混用 |
| 商品词搜不到 | 可按页面要求填写商品词及类目提报 | 教程中的字数示例并不完全一致，以当前页面要求为准 |
| 数量及内容门槛 | 不同示例任务有各自的选品数量、图数、内容占比等要求 | 4 件是当前创作目标，不代表一定满足当前任务 |

## 每单固定流程

| 阶段 | 输入 | 操作与输出 | 进入下一步的条件 |
|---|---|---|---|
| 1. 读取任务 | 本次任务要求、推广入口 | 记录品类、数量、禁投品、图数／尺寸、必带内容、商业合作标识及截止时间 | 要求明确；不足 4 件或超过 4 件时先调整方案 |
| 2. 分析穿搭图 | 原始照片 | 拆出待推广的服饰部位、可见特征、搜图裁切区域与搜索关键词 | 用户确认需要推广的 4 件是什么 |
| 3. 搜索候选 | 裁切图、关键词 | 记录商品截图、链接、标题、店铺名和同款／相似款判断 | 不以外观相似替代商品核实 |
| 4. 核对推广项 | 候选商品、对应任务 | 搜索店铺词和商品词；找不到时精简搜索、换候选或提报 | 本单需要的推广项确认可用 |
| 5. 锁定商品与文案 | 4 件已确认商品、创作方向 | 确定标题、正文、话题及每件商品的图片短语 | 文案与真实商品、任务要求一致 |
| 6. 模板合图 | 确认后的文字、原图、商品素材 | 按固定版式排版，导出新文件；不覆盖原图 | 无遮挡、越界、错配或无法阅读的小字 |
| 7. 人工审核交付 | 成品图、文案、推广对应表 | 检查本单要求及实际绑定项 | 用户确认后再提交或发布 |

文案方向可以提前起草，但商品名称、推广词、价格等相关的最终文案，必须在商品锁定后确认；最终文字确认后再合图。

确认状态统一使用：未搜索、已找到候选、待提报、待审核、已确认可用、不可用。

## 短语与小红书文案

### 图片短语

- 先描述照片能确认的颜色、轮廓、搭配关系和风格；长短根据实际版式确定。
- 材质、品牌、功能、价格及优惠必须有商品资料支持，不能从照片推断。
- 不编造“显瘦几斤”“全网最低”等效果或比较承诺。
- 未购买、未穿着的推广商品，不能写成自己实际购入或实穿的同一件。
- 相似款需明确区分，不把同风格推荐写成照片原款。

### 每单文案交付

1. 待确认的小红书标题。
2. 正文：穿搭主题、搭配说明、与已确认商品一致的介绍及必要推广内容。
3. 话题与商业合作标识：以本次任务和平台要求为准。
4. 4 件商品各自的图片短语，与商品对应表保持一致。

正式生成前需要用户提供一篇自己的既往笔记，或一份喜欢的文风参考；没有参考时只出中性草稿，不擅自编造个人经历。

## 最小自动化范围

先跑通一单，再固定模板；不先开发账号系统、后台、数据库或多平台发布系统。

| 模块 | 首版目标 | 实现前需要确认 |
|---|---|---|
| 图片分析 | 识别可见穿搭特征、生成搜图裁切建议和关键词 | 一张真实穿搭原图 |
| 浏览器辅助 | 在实际页面中辅助搜候选、查询推广词并记录结果 | 实际网址、登录后的页面、是否支持图片上传 |
| 信息对应 | 用上面的表格保存商品与推广项关系 | 先手工跑通，不提前做数据库 |
| 文案生成 | 基于同一份商品信息生成标题、正文与图片短语 | 任务要求、真实商品资料、文风参考 |
| 固定模板合图 | 保留原图，输出带文字／商品素材的待审核成品 | 合格成品参考、输出尺寸、使用中的设计工具 |
| 发布提交 | 首版保留人工确认和操作 | 不自动点击最终提交或发布 |

暂不选定图像处理库、浏览器脚本框架或新增第三方服务。先确认已有网站和设计工具能否完成任务，再补最少的自动化。

## 安全与质量边界

- 不索要或上传密码、验证码、Cookie、访问令牌及会话文件；登录由用户完成。
- 本次仓库仅保存流程文档，不上传教程原图、个人穿搭照片、商品图片或商单截图。
- 后续若需把原图上传到搜图网站或图像服务，先确认服务及上传范围。
- 不绕过验证码、平台风控、访问限制或任务资格要求；遇到限制暂停该步并记录。
- 不覆盖原始素材；所有合成结果另存。
- 价格、库存、优惠和推广资格是动态信息，使用与提交时都需核对。

## 回家后的继续入口

第一步只需准备：一张真实穿搭原图，以及“添加推广店铺／商品词”页面的主网址或无登录凭证的地址。

随后按流程逐步补充：

- [ ] 当前商单要求，尤其是数量、禁投品、推广标识和截止时间。
- [ ] 之前已经找过的一件商品链接，以及对应搜不到的推广入口截图。
- [ ] 一份合格成品参考和输出尺寸。
- [ ] 正在使用的浏览器设计／修图工具名称。
- [ ] 一篇既往笔记或文风参考。
- [ ] 完成第一件商品的“原图 → 候选 → 可用推广项”核对。
- [ ] 完成一份短语与正文草稿，确认后合成样图。
- [ ] 样图通过人工确认后，再扩展到 4 件并固化重复步骤。

## 首单验收标准

- 实际选品数量符合本次任务；若任务不允许只放 4 件，先解决数量差异。
- 每件商品可追溯到原图部位、候选链接和本单需要的可用推广项。
- 待审核、不可用和相似款没有被错误标成已通过或原款。
- 图片短语、正文、商品和实际推广绑定无错配，没有未经核实的事实或体验宣称。
- 成品尺寸、图数、可读性、广告标识及禁投要求符合本单规定。
- 原图保留完整，成品和文案可找回；用户审核后才提交。
